# AI Evaluation Report

## 1. Evaluation Objective

The objective of this evaluation is to assess the ability of
the Qwen2.5:7b-instruct model to extract tasks, classify them
into Study, Work, and Personal categories, and identify
deadlines from English text.

## 2. Evaluation Method

Five manually prepared test cases were used.

The expected outputs were compared with the actual outputs
generated by the AI model.

A prediction was considered correct only when the task,
category, and deadline matched the expected values after
normalizing capitalization and whitespace.

## 3. Evaluation Results

| Test Case | Result | Observation |
|-----------|--------|-------------|
| 1 | Pass | Correct task, category, and deadline |
| 2 | Pass | Correct task and category with no deadline |
| 3 | Partial Match | Deadline returned as "Monday" instead of "on Monday" |
| 4 | Pass | Correctly identified text without tasks |
| 5 | Pass | Correctly extracted two separate tasks |

## 4. Performance Metrics

- Precision: 80.00%
- Recall: 80.00%
- F1 Score: 80.00%

## 5. Error Analysis

The model successfully identified the intended task and
category in Test Case 3.

However, the predicted deadline was "Monday", while the
expected deadline was "on Monday".

Because the evaluation uses exact matching, this difference
was counted as an incorrect prediction.

The two deadline expressions refer to the same day, but
the model did not preserve the complete original phrase.

## 6. Conclusion

The AI model achieved an F1 score of 80% using strict
exact-match evaluation on five manually prepared test cases.

The results show that the model can extract and classify
tasks in the evaluated examples.

However, the evaluation also identified a limitation in
preserving exact deadline expressions.

Further evaluation with a larger and more diverse dataset
is recommended.
